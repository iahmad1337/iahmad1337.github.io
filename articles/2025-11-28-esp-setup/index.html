Once you connect esp32 to computer via usb, it won't be visible in lsusb right off the bat. What you have to do is to establish serial connection

The port of my devboard is /dev/ttyUSB0 - it can be determined by plugging/unplugging the board and tracking the difference.

Now, let's see what the board tells us if we press EN (reset) button while listening on serial port:

$ sudo usermod -a -G dialout $USER
$ sudo usermod -a -G uucp $USER

< logout >

$ sudo apt install minicom
$ minicom -D /dev/ttyUSB0
